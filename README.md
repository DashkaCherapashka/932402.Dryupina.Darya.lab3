## Описание

Дополнение страницы из ЛР2 навигационным меню (Flexbox), карточками релизов (Flexbox) и дашбордом студийного оборудования (CSS Grid). Реализована адаптивная вёрстка.

## Что реализовано

### Flexbox
- Навигационное меню — горизонтальное, адаптивное
- Карточки релизов — 4 шт., на планшете 2, на мобильном 1

### CSS Grid
- Дашборд «Студийное оборудование» — 3×2
- На планшете — 2 колонки, на мобильном — 1

### Семантика
- `<nav>` — навигация
- `<article>` — карточки релизов и оборудования
- `<section>` — секции страницы
- `<time datetime="2026">` — год релиза

### Адаптивность
- Медиа-запросы на 992px, 800px и 640px
- Карточки релизов: 4 → 2 → 1
- Сетка оборудования: 3 → 2 → 1
- Нет горизонтальной прокрутки

### Доступность
- Контраст текста ≥ 4.5:1
- Alt-тексты у всех картинок

## Файлы

- `index.html` — основная страница
- `style.css` — стили
- `images/` — картинки (аватар, фон, обложки, оборудование)
- `README.md` — описание
